# Carrinho de Compras

Projeto de estudo desenvolvido durante o bootcamp da **DIO (Digital Innovation One)**.

A aplicação simula um carrinho de compras inspirado em plataformas de comércio eletrônico, permitindo adicionar, remover e listar produtos, além de calcular o valor total da compra.

## Sobre o projeto

Este projeto foi desenvolvido acompanhando as videoaulas do bootcamp, reproduzindo os exemplos apresentados pelo professor e praticando os conceitos demonstrados durante as aulas.

O objetivo principal foi praticar lógica de programação, manipulação de dados e organização de código utilizando JavaScript e Node.js.

## Funcionalidades

* Adicionar produtos ao carrinho
* Remover produtos do carrinho
* Listar produtos adicionados
* Calcular o valor total da compra

## Tecnologias

* JavaScript
* Node.js

## Estrutura do projeto

O projeto possui uma estrutura simples, dividida em:

* `src/index.js` — ponto de entrada da aplicação
* `src/services` — serviços responsáveis pelas funcionalidades do carrinho
* `package.json` — configuração do projeto Node.js

## Conceitos estudados

* Lógica de programação
* JavaScript
* Node.js
* Modularização de código
* Manipulação de arrays
* Manipulação de dados
* Funções e operações com produtos
* Cálculo de valores

## Contexto

Projeto desenvolvido como parte do bootcamp da DIO, acompanhando as explicações e exemplos apresentados durante as aulas.

Este repositório faz parte do meu histórico de estudos e representa um dos projetos utilizados para praticar conceitos básicos de JavaScript e Node.js.
